# DeCamisetas.com

Este sitio es un proyecto de práctica para el curso de ReactJS de CoderHouse. En el mismo se simula un ecommerce de camisetas de futbol, permite ver los productos, filtrarlos por categoria y realizar la compra. Los productos y las ordenes de compra se almacenan en Firebase

## Tecnologias utilizadas

Para la realizacion del mismo se utilizo:
* Vite 5.4.0
* React 18.3.1
* React-router-dom 6.26.2
* Toastify 10.0.6
* Firebase 10.14.0

## Funcionalidades

En la aplicacion se puede:
* Ver el listado de productos
* Filtrar por categoria
* Ver el detalle de cada producto
* Agregar productos al carrito
* Ver el detalle del carrito
* Efectuar una compra

## Instalacion

Para instalar y ejecutar la aplicacion en tu maquina loca, sigue los siguientes pasos:

1. Clona el repositorio en tu maquina local.
2. Abre una terminar en el directorio del proyecto.
3. Ejecuta el comando npm install apra instalar las dependencias en base al packaje.json
4. Ejecuta el comando npm run dev para inciar la aplicacion
Abre tu navegador y navega a http://localhost:5173 para ver la aplicacion en accion.
